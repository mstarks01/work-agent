# QA-2026-11-01-01: does the structure Mermaid's parsers read help extraction?

Scope: the first paid measurement of ADR 0121's structure reader, on
flowcharts and on `architecture-beta` diagrams. Mode implement, two grants of
$1.50 and $0.80, $2.0680 metered at list price (an upper bound).

**Status: closed.** E1 is refuted: the structure helped `architecture-beta`
diagrams and harmed loose flowcharts. E2 is supported: with two flowchart
corrections, the structure helps loose flowcharts too. The candidate was
merged as #2083.

## Before the experiment

1. **The open question.** ADR 0121 puts the structure that Mermaid's own
   parsers read beside each `diagram` Source, and the gate holds extraction to
   it. No paid run has measured what that does to elements lost.
2. **The candidate.** `fix/architecture-beta-reading`, on `main` at
   `6c817e77`. It adds three corrections for `architecture-beta`: the reader
   lists junctions, takes each line from the parser's position, and starts a
   `{group}` edge at the node's group. The register names a group beside a
   subgraph, and says a junction is never an element.
3. **The before side.** `480ef2c3`, the last `main` without the reader. It
   reads each diagram as text. No prompt byte differs between the two
   revisions for a job without a `diagram` Source.
4. **The outcome.** Elements lost per sweep, as QA-2026-10-31-03 defines it.
5. **The falsifier.** On a set, the after mean is not at or below the before
   mean less half the before standard deviation.
6. **The experiment.** Four rounds. Each round runs one sweep of each arm,
   in this order: architecture before, architecture after, drawn before,
   drawn after. All 16 cases, `gpt-5.6-luna` through OpenRouter, three cases
   in flight. Each arm is replayed with `run.py replay` over `evals/corpus`.
   - **architecture:** `QA-2026-11-01-01/architecture/`, written by
     `build_architecture.py` from each blessed model. A zone is a group
     titled `Trust zone <name>`, and an element is a service with Mermaid's
     icon for its kind. Mermaid gives an architecture edge no label, so no
     flow name is in the diagram. Mermaid refuses cases 02 and 16, because a
     name holds a character its architecture grammar does not admit. So those
     two read as text on both sides.
   - **drawn:** `QA-2026-10-31-04/drawn/`, loose flowcharts. A person read
     them on 2026-11-01 and found them fine.
7. **Cost.** Metered from each artifact's tokens at OpenRouter's list price,
   an upper bound. A diagram sweep read $0.08 to $0.10, and the structure
   adds input tokens, so 16 sweeps read about $1.50. A sweep that would take
   the spend past $1.48 does not start. An arm with fewer than three sweeps
   on each side is inconclusive.

## The gate

| Set | Supported | Harm | Otherwise |
| --- | --- | --- | --- |
| architecture | after ≤ before − 0.5 before sd | after > before + 0.5 before sd | inconclusive |
| drawn | after ≤ before − 0.5 before sd | after > before + 0.5 before sd | inconclusive |

The candidate's corrections go to `main` where neither set reads harm. The
clean flowchart set is not run: its exports carry the shape convention, and
it gave 2.75 elements lost a sweep without the structure.

**Read, not gated:** `mistyped`, `omitted`, `endpoint_unaligned`, the
`diagram-node-missing` and `diagram-edge-missing` issues the repair pass met,
and the cases the gate refused.

## E1 result

All 16 sweeps ran, $1.3391 metered at list price. Elements lost per sweep,
from `run.py replay` over `evals/corpus`:

| Set | Before (`480ef2c3`) | After (`8c0f11a4`) | Line | Reading |
| --- | --- | --- | --- | --- |
| architecture | 6, 9, 6, 14 (mean 8.75, sd 3.77) | 6, 4, 6, 4 (mean 5.0) | ≤ 6.86 | supported |
| drawn | 77, 76, 87, 81 (mean 80.25, sd 4.99) | 86, 87, 89, 89 (mean 87.75) | harm above 82.75 | harm |

- **The architecture gain.** Mistyped elements fall from 3.0 to 1.5 a sweep,
  and unaligned flow endpoints from 3.5 to 1.5. The text alone already gives
  every element, so the gain is small in count.
- **The drawn harm has two causes.** A drawn diagram shows a queue, such as
  `Pub/Sub` or `Render queue`, as a plain rectangle. With the structure, which
  prints each node's shape, extraction types the queue as a process. Store
  mistypes rise from 1 to 10 over four sweeps, and each mistype unaligns its
  flows. The structure sentence also asks for each element to be named with
  its node's label. Case 13 labels a node `Dispatch database: job orders,
  crew names, crew mobile numbers`, so the element takes that whole label, and
  the replay cannot pair it with `dispatch database`. Case 13 alone adds 11
  lost elements over four sweeps.
- **Limits.** The architecture diagrams are written from the blessed models,
  with an icon for each element kind, so that gain is an upper bound. The
  extraction mode runs no repair, so this measures the structure as evidence
  in the prompt, not the gate's repair of a gap.

## E2: before the experiment

A second grant of $0.80. The user chose to fix the two causes of the drawn
harm and keep the structure for both diagram types.

1. **The candidate.** `efc0087b`: the structure gives no flowchart shape, an
   element can take the part of a node's label before its first colon or
   bracket, and the gate accepts either name.
2. **The experiment.** Four drawn sweeps at `480ef2c3` and four at
   `efc0087b`, in turn, over `QA-2026-10-31-04/drawn`. The architecture set is
   not run again: for it the candidate changes one register clause, and no
   architecture label in the set holds a colon or a bracket.
3. **The gate.** No harm: the after mean is at or below this run's before
   mean plus half its standard deviation. Otherwise refuted.
4. **Cost.** About $0.75. The spend stop for the audit rises to $2.28, the sum
   of both grants less a margin.

## E2 result

All eight sweeps ran, $0.7289 metered at list price, $2.0680 for the audit
of the $2.30 granted.

| Set | Before (`480ef2c3`) | After (`efc0087b`) | Line | Reading |
| --- | --- | --- | --- | --- |
| drawn, in turn | 84, 77, 80, 81 (mean 80.5, sd 2.89) | 75, 75, 74, 73 (mean 74.25) | ≤ 81.94 | supported |

- **The harm is gone, and the structure now helps.** Each after sweep loses
  fewer elements than each before sweep. Unresolved data stores fall from 38
  to 16 over four sweeps, because a store whose node label carries detail now
  takes the short name.
- **Read, not gated.** Mistyped external entities rise from 5 to 12 over four
  sweeps. The extraction mode now reports each diagram issue on the score;
  in a job, the repair pass reads them.

## Decision

The candidate is kept. `fix/architecture-beta-reading` goes to `main` as its
own pull request: the architecture corrections of E1, the two flowchart
corrections of E2, and the harness's diagram gate.
