# QA-2026-10-13-03: one call or two for the question-kind predicates

The design for a field per question kind puts each kind's parts in the
assertion catalog as predicates: the 6 parts an existing predicate answers
reuse it, and 28 parts get a new term predicate (`present`, `absent`,
`not-applicable`). This audit compares the two ways to write the 28:

- **Arm A**, one call: the assertion pass reads all 51 predicates.
- **Arm B**, two calls: the assertion pass reads today's 23, and a second
  call of the same node reads only the 28.

Both arms run the shipped assert node through the assert-only graph on a fixed
model, so they read the same input. Model `gpt-5.6-luna` on OpenAI. The
maintainer granted $1.25; the test spent $0.50 (preflight $0.015, corpus
$0.434, example $0.050).

## Today's rows are not harmed by the larger table (E1)

The 14 non-holdout corpus cases, three runs of each state
(`corpus-arms.json`). The baseline is arm B's first call.

| Per case, mean of 3 runs | Baseline | Arm A |
| --- | --- | --- |
| Jaccard of today's rows against a baseline run | 0.591 (its own spread) | 0.586 |

Arm A moves today's rows no more than a second baseline run does.

## The second call states more parts, for half the price again (E2)

| Corpus, 3 runs | Arm A | Arm B |
| --- | --- | --- |
| Question-kind parts stated | 24 | 40 |
| Run-to-run Jaccard of the parts | 0.709 | 0.671 |

Where both arms state a part, they give the same value in 8 of 8. The corpus
descriptions are written with weaknesses, so most stated parts are `absent`,
and only 7 of the 28 predicates appear.

## A full description closes few parts in either arm (E3)

The example description with run 4's model of it (QA-2026-10-13-02), three
runs of each state (`example-arms.json`). Run 4's list holds 23 question-kind
questions with 67 parts.

| Example, runs 1-3 | Parts closed | Questions closed |
| --- | --- | --- |
| Today | 0, 0, 0 | 0 |
| Arm A | 5, 3, 5 | 0 |

The rows sit on the elements the questions ask about. The example states one
part of a question for a few elements ("100 requests per minute" is the rate,
not the size, the concurrency or the quota), and each kind is asked of up to
nine elements, so no question has every part stated. Some of arm B's extra
rows read more than the text says: "reachable only from inside the VPC" as
named callers, and "with its own IAM role" as least privilege.

## Scripts

The arms were applied to the working tree by the script below, never
committed. `arm_state.py base|prompt|node` restores the shipped files, then
adds the 28 predicates, a `RENDERED` table that the prompt and the schema read
(all 51 for arm A, the 28 for arm B's second call), and a `NoRule` reader for
each new predicate in both packages.

```python
"""Put the working tree into one arm's state: base, prompt (arm A) or node (arm B's second call)."""
import pathlib, subprocess, sys

state = sys.argv[1]
A = pathlib.Path("src/analysis_service/assertions.py")
P = pathlib.Path("src/analysis_service/prompts.py")
R = [pathlib.Path(f"src/analysis_service/frameworks/{n}/rules.py") for n in ("stride", "asvs")]
subprocess.run(["git", "checkout", "--", str(A), str(P), *map(str, R)], check=True)
if state == "base":
    raise SystemExit(0)

KINDS = '''

# ---- Test arms (QA-2026-10-13-03): one predicate per question-kind part ----
from analysis_service.question_kinds import QUESTION_KINDS as _QUESTION_KINDS  # noqa: E402

#: The parts an existing predicate already answers.
_ANSWERED_ALREADY = {
    ("reachability", "internet"), ("audit-evidence", "records-actor"),
    ("destination", ""), ("provenance", "sender"), ("provenance", "integrity"),
    ("content-validation", "validates"),
}
KIND_PREDICATES: dict[str, Predicate] = {}
for _kind, _question in _QUESTION_KINDS.items():
    for _facet in _question.facets or (None,):
        _part = _facet.id if _facet else ""
        if (_kind, _part) in _ANSWERED_ALREADY:
            continue
        _text = _facet.question if _facet else _question.template.replace(
            "{element}'s", "its").replace("{element}", "it")
        KIND_PREDICATES[f"{_kind}-{_part}" if _facet else _kind] = Predicate(
            meaning=f"the answer to \\"{_text}\\" for this subject: `present` for"
            " yes, `absent` for no, `not-applicable` where it does not apply",
            subjects=frozenset({"component", "interaction"}),
            value="term",
            terms=frozenset({"present", "not-applicable"}),
        )
REGISTRY = MappingProxyType({**REGISTRY, **KIND_PREDICATES})
RENDERED: Mapping[str, Predicate] = __RENDERED__
'''.replace("__RENDERED__", "REGISTRY" if state == "prompt" else "MappingProxyType(KIND_PREDICATES)")

s = A.read_text()
anchor = '''            stated_only=True,
        ),
    }
)
'''
assert s.count(anchor) == 1
s = s.replace(anchor, anchor + KINDS)
old = 'json_schema_extra={"enum": [*sorted(REGISTRY)]},'
assert s.count(old) == 1
s = s.replace(old, 'json_schema_extra={"enum": [*sorted(RENDERED)]},')
A.write_text(s)

p = P.read_text()
p = p.replace("from analysis_service.assertions import REGISTRY, Predicate, referent_type",
              "from analysis_service.assertions import RENDERED, REGISTRY, Predicate, referent_type")
old = "    for name, predicate in REGISTRY.items():\n        subjects ="
assert p.count(old) == 1
P.write_text(p.replace(old, "    for name, predicate in RENDERED.items():\n        subjects ="))

for rules in R:
    text = rules.read_text()
    text += """

# ---- Test arms (QA-2026-10-13-03) ----
from analysis_service.assertions import KIND_PREDICATES as _KIND_PREDICATES  # noqa: E402

PREDICATE_READERS = MappingProxyType(
    {**PREDICATE_READERS, **{name: NoRule("read by the question list (test arm)") for name in _KIND_PREDICATES}}
)
"""
    rules.write_text(text)
```

`example_arm.py` runs the assert-only graph on the example and run 4's model:

```python
"""Run the assert-only graph on the example and run 4's model; save the catalog and usage."""
import asyncio, json, sys
from pathlib import Path
from types import SimpleNamespace
from analysis_service.deployment import Deployment
from analysis_service.graph import ENTRY_ASSERT_ONLY
from analysis_service.jobs import Checkpoint
from analysis_service.sources import Source
from evals.harness import modes

out = Path(sys.argv[1])
cp = Checkpoint.model_validate_json(Path(sys.argv[2]).read_text())
text = Path("examples/orders.md").read_text(encoding="utf-8")
case = SimpleNamespace(id="example", model=cp.system_model,
                       sources=[Source.description(text, label="Pasted description")])
pipeline = modes.build_eval_pipeline(ENTRY_ASSERT_ONLY, deployment=Deployment.from_env(), frameworks=("stride",))
result = asyncio.run(modes.run_assertions(case, pipeline))
usage = [n.model_dump(mode="json")["usage"] for n in result.node_runs if n.model_dump(mode="json").get("usage")]
out.write_text(json.dumps({"entries": result.record.catalog.model_dump(mode="json")["entries"], "usage": usage}, indent=1))
print(out.name, len(result.record.catalog.entries), "rows", usage)
```
