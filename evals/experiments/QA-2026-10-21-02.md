# QA-2026-10-21-02: native structured output against the forced tool, on one model

Scope `analysis`, mode `audit`, one grant of $23; about $4.90 spent, priced
from token counts at list rates, because the `anthropic` row reports no
charge. The artifacts are under `evals/runs/20261021T-1413-tool-vs-native/`,
which git does not track. The question is #1413's.

## The design

- Model: `claude-haiku-4-5` on every tier of the `anthropic` row. It takes
  native structured output and a tool call on one route.
- No thinking level, so the tool arm is the forced tool. Anthropic refuses a
  forced tool together with thinking.
- Arms: strong `structured_output = "native"` and `"tool"`. Nothing else
  differs. The base tier stays native on both arms.
- Five analysis-mode runs of case 01, STRIDE only, on each arm. The archive
  holds no run on this route, so no spread existed to read first.

Every node recorded the path of its arm (`schema-paths`), and no rung fell
back.

## Results

| | native | tool |
| --- | --- | --- |
| jobs finished | 5 of 5 | 4 of 5 |
| must-find of 8 | 6, 5, 7, 5, 6 | failed, 6, 7, 7, 7 |
| coverage | 0.63-0.74 | 0.63-0.79 |
| critic re-asks | 0 of 5 | 3 of 4 finished runs, and the failed run |
| lane re-asks | 0 | 0 |
| cost a run | $0.47-$0.53 | $0.43-$0.55 |

Tool run 1 failed in the critic: after the re-ask, 15 claims in
`ThreatRulings` still had no `confidence` field.

## What follows

- When a tool run finishes, its quality is inside the native spread.
- The critic's first answer failed the schema in 4 of 5 tool runs and in no
  native run. One tool job in five failed on it.
- So the falsifier holds: the tool arm failed more jobs than the native arm.
  Whether the `auto` default may still fall back to the tool path is the
  maintainer's ruling on #1413.
- The offered tool, which a thinking model reaches, is unmeasured.
