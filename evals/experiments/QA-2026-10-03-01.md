## E1: how many critic citations wait on one facet (#1306)

Since ADR 0050, the report page counts a finding as covered only when every
facet of each kind it waits on has an answer. #1306 asks the critic to name a
facet, so that the count follows the one facet a finding needs.

E11's two archived critic passes hold 249 citations of a kind with facets. Each
verdict reason was read for the facets it names:

| Kind | Cited | One facet (by reading) |
| --- | ---: | ---: |
| `authorization-scope` | 57 | about 12 |
| `stored-copy-access` | 52 | 4 |
| `capacity-limits` | 48 | 0 |
| `reachability` | 42 | 42 |
| `audit-evidence` | 37 | 9 |
| `content-validation` | 4 | 4 |
| `provenance` | 4 | 0 |
| `data-exposure` | 3 | 3 |
| other | 2 | 0 |

About 80 of 249 citations, a third, wait on one facet. Every `reachability`
citation asks whether a foothold can reach or observe an internal interface,
which is the `named-callers` facet. No `capacity-limits` citation waits on one
facet: each lists several capacity controls.

**What it means for the decision.** The count informs the page and rules on
nothing. `covered_so_far` is coverage, not a verdict, and an answer reaches the
lanes once one facet says more than `unknown`. So a facet count cannot change a
finding or a must-find, and its ceiling on report quality is zero. It makes the
page's count correct sooner for about a third of the citations. That gain shows
only when a submitter answers some facets of a kind and leaves the others
`unknown`, and no real submission has measured how often that happens (#1286).

**Recommendation.** Keep #1306 deferred, and do not spend the replay. Build it
when #1286 shows that submitters leave facets unanswered, or when the count
gates a step.

The file `QA-2026-10-03-01/facet-citations.csv` holds one row per citation, with
the facets the word table found. The `named` column is the word table's
reading, before the corrections above. The script that wrote it:

```python
"""Which facets of its kind each E11 critic citation's reason names."""

import csv
import glob
import json
import re
import sys

from analysis_service.question_kinds import QUESTION_KINDS

# The words that name each facet in a critic's reason, from one reading of
# the 249 citations. A reason that names no facet's words waits on the kind.
WORDS = {
    "capacity-limits": {
        "rate": r"\brate\b|rate-limit|request-rate|throughput|request limits|admission",
        "size": r"size|depth|entity-expansion|object-count|byte",
        "concurrency": r"concurren|connection|worker|fan-out|slot|queue|load.shedding|state-memory|processing",
        "quota": r"quota|budget|spend|cost|egress",
    },
    "audit-evidence": {
        "records-actor": r"attribut|identif|bind|individual|records that party|resolved to a verified|origin|actor|coverage and contents|coverage and evidence",
        "record-protected": r"durable|immutable|protect|retain|preserv|amendment or deletion",
    },
    "authorization-scope": {
        "checks-each-request": r"per-request|each request|every rota-write|each rota-write|per-action|server-side authoriz|re-authoriz|enforces authorization|authorization of",
        "least-privilege": r"narrow|scope|role|authority available|grant|exceed",
        "checks-ownership": r"ownership|own uploads|per-object|per-document|target account|target identifiers",
    },
    "stored-copy-access": {
        "encrypted": r"encrypt|at-rest protection",
        "restricted": r"access|obtain|who can|copied",
    },
    "reachability": {
        "internet": r"internet|public",
        "named-callers": r"foothold|reach|observe|on-path|observation|unauthorized parties",
    },
    "provenance": {
        "sender": r"authenticat|server-identity|impersonat|attacker-originated|provenance",
        "integrity": r"altered|provenance|integrity",
    },
    "content-validation": {
        "validates": r"validat",
        "encodes": r"encod|bind",
    },
    "data-exposure": {
        "minimal-fields": r"payload|information|fields",
        "clean-logs": r"diagnostics|logs",
        "restricted-readers": r"readers|authoris",
    },
    "security-configuration": {
        "cookies": r"cookie",
        "headers": r"header",
        "cross-origin": r"origin",
        "secret-store": r"secret",
    },
    "update-process": {
        "scheduled": r"schedule",
        "vulnerability-alerts": r"vulnerab",
        "tested": r"tested",
    },
}

writer = csv.writer(sys.stdout)
writer.writerow(["pass", "case", "claim", "kind", "element_id", "facets", "named", "reason"])
for path in sorted(glob.glob("evals/runs/20260927T-critic-question-kinds/*/*.rulings.json")):
    sample = path.split("/")[-2]
    case = path.split("/")[-1].split(".")[0]
    for claim in json.load(open(path))["claims"]:
        reason = claim["verdict"]["reason"]
        for ref in claim["verdict"]["related_unknowns"]:
            kind = QUESTION_KINDS.get(ref["question"])
            if kind is None or not kind.facets:
                continue
            named = [f for f, rx in WORDS[ref["question"]].items() if re.search(rx, reason, re.I)]
            writer.writerow([sample, case, claim["id"], ref["question"], ref["element_id"],
                             len(kind.facets), ";".join(named), reason])
```
