## Answers

**What is hurting report quality?** Two defects of the Controls critic step
(#2171): each reached draft repeated each evidence text, and the seam
accepted a `control` rejection that quotes nothing it rests on. The longer
critic prompt may move verdicts on jobs with no Control; that is unmeasured.

**Which phase is responsible, how confidently, and what alternatives remain?**
Criticism, for all three. Findings 1 and 2 are reproduced in the production
functions. Finding 3 has no evidence either way.

**What is the proposed fix?** Findings 1 and 2: #2198, merged. Finding 3: no
fix until it is measured.

**What was changed, and what was measured?** #2198 (`53de694a`). E4 and E5
measure it offline. E4 and E5 have no `candidate` block: #2198 adds a row
to `.github/scripts/prompt_outcomes.toml`, a protected path, so `--record`
refuses it as a candidate, and the fix went through the ordinary pull request
review with the standards read, the security review and the full suite. No
ruling exempts it; the regressions and the head (`b9e04b25`) are in each
row's scope.

**What did not work?** E1 and E7 are refuted: neither #2171 (E1, at `87e4c466`) nor the code after the #2198 fix (E7, at `53de694a`) changes the assembly of the 13 archived STRIDE blocks. E6 is inconclusive: the approved critic test did not run.

**What remains untested or blocked?** Finding 3's live test (provider
credit). The re-ask repair rate of the new quote problem. A limit on a job's
total evidence text, which is the maintainer's decision.

**What was spent, and what remains?** $0 of the $2 grant.

**What needs fresh model output, and which decision does it change?**

The critic test of finding 3, approved at $2 and blocked. The pre-flight call
(case 02, at `87e4c466`, before the plan moved arm B to `53de694a`) failed with `invalid_request_error`: "Your credit balance is
too low to access the Anthropic API" (request `req_011Cgky2LxquZ9eEmH1NVhhu`).
Another model is not a substitute, because the archived sweep ran on Sonnet 5.

1. **Question.** Does the control step move the critic's verdicts on drafts that carry no `controls`? If yes, render step 3 only when a draft carries `controls`. If no, keep the prompt as it is. `prompts/critic.md` is shared, so either decision changes ASVS too.
2. **Offline checks.** E1 and the word counts above.
3. **Ledger.** No earlier row tests #2171; E1 tests only the deterministic assembly. QA-2026-10-08-02 E3 and E5 tested another prompt edit; `prompts/critic.md` changed since, so they are stale.
4. **Why no free check answers it.** The question is what the model rules. A replay of an archived verdict is not new model output.
5. **Stage and cases.** The critic only, by `critic-replay`, on the 13 STRIDE cases of `20261024T-sonnet-medium-sweep`, Sonnet 5, as archived. ASVS: this audit read no archived ASVS sweep, so the plan has no ASVS case yet; the next audit names one before a change to the shared prompt is decided.
6. **Metric and plan.** The share of drafts whose verdict differs between two fresh arms on the same drafts, both at `53de694a`, the code main ships. Arm B: the shipped prompt. Arm A: the same commit with a patch that removes the control step and the `controls` paragraph from `prompts/critic.md` and the Control section from `frameworks/stride/critic.md`. So the arms differ only in that text, and other critic changes since the sweep (#2149, #2172, #2188, #2192, #2198) are in both. The archived verdicts are not the reference, because the critic code and prompt changed between the sweep's commit (`5d75b23f`) and `53de694a`. One pass in each arm measures no band, so this plan can only flag a difference: a difference inside the 7.5% of QA-2026-10-08-02-E5 (another model and prompt) is inconclusive, and a decision then needs a second pass of arm A, which needs a new grant.
7. **Spend.** Unpriced. No per-call price of this critic on Sonnet 5 is on record; QA-2026-10-08-02-E3 spent $0.8325 on terra for a different set of calls, including one ASVS case of 203 drafts. The pre-flight case gives the price; if 26 calls at that price exceed the $2 grant, stop and ask before arm A. A retry of one case costs one call at that price.
8. **If null.** Record it and keep the prompt. If adverse, propose the conditional step. If inconclusive, stop; do not add passes without a new ask.

The re-ask repair rate of the quote problem is not proposed here. The next
audit writes its eight answers before it asks.

**What should the next audit do first?**

3. Ask the maintainer whether a job needs a limit on the total evidence text of its Controls.
