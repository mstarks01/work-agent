# QA-2026-10-09-03: can the assertion catalog change a report?

For [#1231](https://github.com/mstarks01/work-agent/issues/1231) item 1:
should `ANALYSIS_ASSERTIONS` stay off by default? The cost of the flag is
measured (about $0.024 and 155 s for each job, #926). Its effect on a report is
not measured. A full-sweep A/B costs too much for the effect it can find: the
corpus spread is 3.37 must-finds, so a gain of 2 needs about 23 runs on each
side.

Both experiments use each case's signed facts as the catalog. That is the most
an assertion pass can write, so a real pass gives no more than these figures.

## E1: the rule path, refuted ($0)

`ceiling.py` runs today's rules on each of the 13 signed cases twice: once with
no catalog, and once with the signed facts as the catalog.

| | STRIDE | ASVS |
| --- | ---: | ---: |
| Must-finds | 103 | 50 |
| No rule leads to them today | 14 | 17 |
| A catalog rule leads to them | 1 | 0 |
| They have a lead and get one more | 4 | 0 |

The one new lead is case 01, reference 7 (`repudiation-record-names-intermediary`).
The rules that read the catalog cannot give a measurable gain.

## E2: the lane path, blocked on an amount

The catalog also reaches every lane as evidence rows that the lane can cite. E1
does not measure that path. E2 measures it with `lane-replay --prepare-today`.
That option runs today's `prepare` offline, with no catalog or with the signed
facts, so the two arms differ only in the catalog.

**The targets.** `targets.py` scores the drafts of two flag-off runs on
`openrouter/openai/gpt-5.6-terra` (Baseline `6bff717` and sweep B) on today's
corpus. Of the 103 STRIDE must-finds, 69 are matched in both runs, 9 in one run
and 25 in neither. A must-find that the lanes always find has no room to gain,
so E2 replays only the 24 lanes that hold the 25 missed must-finds
(`targets.json`).

**The design.** One pass with no catalog and two passes with the signed
catalog, at one revision, on terra. One lane call runs first as a pre-flight.
The drafts are scored before the critic, so the figures are an upper bound.
The estimate is about $3: 72 lane calls at $0.041, the mean lane call of sweep
B.

**The decision rule, stated before the runs.**

- If no signed pass matches a target, the hypothesis is refuted and the flag
  stays off.
- If the signed passes match a mean of 2 or more targets above the pass with no
  catalog, more passes follow before a verdict: about 9 on each side, about $26.
- Any other result is inconclusive, and the maintainer decides.
