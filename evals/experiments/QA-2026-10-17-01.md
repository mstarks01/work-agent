# QA-2026-10-17-01: the rule 3 name sentence of #1813

Scope `extraction`, mode `audit`, budget `$0.50` in one grant. The maintainer
waived the rule that a paid run must also advance an open `needs-sweep` issue,
for this measurement only. No open `needs-sweep` issue (#1476, #1413, #744,
#661) asks for an extraction sweep.

## The question

#1813 adds one sentence to `prompts/extract.md` rule 3: a `name` needs at least
one Latin letter or digit, and the text's own spelling goes in `notes`. No
corpus element name slugs to empty, so the expected effect is null. The
question is whether the sentence moves the extraction figures.

## Why both sides ran

No archived arm can be the before side. The prompt at `bbe33ef8` carries both
the rule 4 edit of #1735 and the rule 6 edit of #1734, and no archived arm ran
both. So both sides ran fresh, on one route, in turn: before, after, before,
after.

The runs used the full extraction route. Its schema is the same at `bbe33ef8`
and at `7cc94c19`, so the prompt is the only input to the model that differs.

## Result

Five sweeps on each side, all 16 cases, gpt-5.6-luna through OpenRouter flex.
Each sweep was replayed alone at `7cc94c19`, and its lost elements were joined
with the must-find claims.

| per sweep, 16 cases | before, `bbe33ef8` | after, `7cc94c19` | change |
| --- | ---: | ---: | ---: |
| elements lost | 17.4 (sd 2.19) | 11.0 (sd 3.16) | −2.9 sd |
| must-find claims on a lost element | 22.0 (sd 2.55) | 13.6 (sd 7.23) | −3.3 sd |
| must-finds at risk in any of five sweeps | 52 of 191 | 28 of 191 | |
| `mistyped` elements | 2.8 | 0.8 | |
| `endpoint_unaligned` flows | 5.0 | 2.8 | |
| sweeps with one case refused by the gate | 3 of 5 | 2 of 5 | |

The difference clears the half-sd bar, but it is not credited to the sentence:

- The difference sits in `mistyped` elements and the flows they leave
  unaligned. The type is wrong in the raw model output: for example, case 11's
  payroll system is a Process in one before sweep. The sentence names no
  element type.
- The archived arms, replayed on the same scorer, read `mistyped` 1.0
  (`20261015T-rule4-app-process`) and 0.8 (`20261016T-rulings-exclusion`).
  The after arm sits with them. The before arm is the outlier.
- Each gate refusal is an assumption that names an attribute or element the
  model does not carry. None is `empty-slug`.

Outcome: inconclusive. The sentence does no measured harm. The gain is not
attributed to it.
