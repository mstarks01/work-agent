## Reproduction

Every command runs offline, with `ANALYSIS_OFFLINE=1`, from a checkout at `8d095db3`. `evals/runs/` is not in git.

```bash
for f in evals/runs/20261024T-sonnet-medium-sweep/[0-9]*.json evals/baselines/*/mstarks01-*.json; do
  uv run python -m evals.harness.run scorecard "$f" --out "out/card-<group>-$(basename "$f" .json).json"
  uv run python -m evals.harness.run panels "$f" --out "out/panels-<group>-$(basename "$f" .json).json"
done
uv run python -m evals.harness.run panels evals/emissions/20261017T-1813-name-rule/after-r1.json \
  --capability-ballot evals/experiments/QA-2026-10-14-02/ballot-returned.csv --out out/panels-emission-after-r1.json
uv run python -m evals.harness.run panels evals/emissions/20260917T-arms-luna-pro/arm-A.json \
  --out out/panels-emission-arm-A.json
python3 -I evals/experiments/QA-2026-11-17-11/summarize.py out > summary.txt
```

`<group>` is `sweep` for the 2026-10-24 sweep and the seven-character Baseline prefix for a Baseline.
