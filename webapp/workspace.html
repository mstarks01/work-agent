How questions work

The page lists the recommended questions, the most useful first. Each answer is saved as you give it, and the page says when a save is pending or failed. Answers can add questions as well as remove them, and the page says when they do. Blank questions stay in the list. Skip for now sets a question aside, where you can answer it later. “None,” “I don’t know,” and a blank answer have different meanings. Only Start the analysis runs the analysis. The report may offer one optional follow-up.
